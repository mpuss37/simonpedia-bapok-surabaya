1. DESKRIPSI SISTEM
================================================================================

SIMONPEDIA Bapok Surabaya adalah sistem monitoring harga bahan pokok
(bapok) untuk wilayah Kota Surabaya. Sistem ini bertujuan untuk:

  - Memantau harga bahan pokok di berbagai pasar Surabaya
  - Mendeteksi anomali kenaikan/penurunan harga
  - Memberikan early warning system (EWS) terkait risiko harga
  - Menyediakan rekomendasi tindakan berdasarkan kondisi pasar
  - Prediksi harga komoditas
  - Integrasi dengan modul Urban Farm

4. DATABASE SCHEMA
================================================================================

  PostgreSQL 18 — Database: simonpedia_bapok

  Wilayah
  |-- id        Int (PK, auto)
  |-- nama      String
  |-- kode      String (unique)
  |-- pasar     Pasar[] (relation)

  Pasar
  |-- id        Int (PK, auto)
  |-- nama      String
  |-- kecamatan String
  |-- kelas     String
  |-- lat       Float? (koordinat untuk peta)
  |-- lng       Float? (koordinat untuk peta)
  |-- wilayahId Int (FK -> Wilayah)
  |-- survei    Survei[] (relation)

  Komoditas
  |-- id           Int (PK, auto)
  |-- nama         String
  |-- kategori     String
  |-- satuan       String
  |-- detailSurvei DetailSurvei[] (relation)

  Survei
  |-- id        Int (PK, auto)
  |-- tanggal   DateTime
  |-- pasarId   Int (FK -> Pasar)
  |-- sumber    String? (contoh: "BAPENAS/SP2KP")
  |-- details   DetailSurvei[] (relation)

  DetailSurvei
  |-- id          Int (PK, auto)
  |-- surveiId    Int (FK -> Survei)
  |-- komoditasId Int (FK -> Komoditas)
  |-- harga       Float

  Relasi:
    Wilayah 1--* Pasar
    Pasar 1--* Survei
    Komoditas 1--* DetailSurvei
    Survei 1--* DetailSurvei

5. REST API ENDPOINTS
================================================================================

  Base URL: http://localhost:3001/api

  GET /api/health
  |-- Response: { status: "ok", message: "SIMONPEDIA API is running" }

  GET /api/komoditas
  |-- Response: Komoditas[]
  |-- Detail: Semua komoditas, sorted by nama

  GET /api/komoditas/:id
  |-- Response: Komoditas (single)

  GET /api/pasar
  |-- Response: Pasar[] (include wilayah)
  |-- Detail: Semua pasar + data wilayah

  GET /api/pasar/:id
  |-- Response: Pasar (single, include wilayah)

  GET /api/harga
  |-- Query params:
  |   |-- pasar_id: number     (filter by pasar)
  |   |-- komoditas_id: number (filter by komoditas)
  |-- Response: Harga[]
  |-- Detail: Join detail_survei + komoditas + (survei + pasar)

  Contoh request:
    GET /api/harga?komoditas_id=9
    GET /api/harga?pasar_id=13&komoditas_id=9

7. CARA RUNNING
================================================================================

  Prasyarat:
  |-- PostgreSQL 18 terinstall dan running
  |-- Node.js 18+
  |-- Database "simonpedia_bapok" sudah dibuat

  7a. Start PostgreSQL (OpenRC):
    sudo rc-service postgresql start

  7b. Buat database (jika belum ada):
    sudo -u postgres createdb simonpedia_bapok -O postgres

  7c. Import data real (jika belum):
    cd server
    npm install
    ./node_modules/.bin/prisma migrate dev --name init
    ./node_modules/.bin/ts-node prisma/import.ts

  7d. Jalankan Backend (terminal 1):
    cd server
    npm run dev
    # Server running on http://localhost:3001

  7e. Jalankan Frontend (terminal 2):
    npm run dev
    # Frontend running on http://localhost:5173

  7f. Verifikasi:
    curl http://localhost:3001/api/health
    # {"status":"ok","message":"SIMONPEDIA API is running"}
